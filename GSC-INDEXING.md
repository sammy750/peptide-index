# Search Console indexing plan — peptideindex.info

Generated 2026-07-29 from the live sitemap. **98 URLs total.**

## Do this first, before any individual requests

1. **Submit the sitemap.** Search Console → Sitemaps → enter `sitemap.xml` → Submit.
   This is worth more than every manual request below combined: it is how Google
   discovers all 98 URLs, and it keeps working as content is added.
   Full URL: `https://peptideindex.info/sitemap.xml`
2. **Check Settings → Ownership verification** shows the property as verified.
3. Only then work through the daily batches.

**Why batches:** "Request indexing" in the URL Inspection tool is rate-limited to
roughly 10–12 URLs per property per day. Submitting more just gets refused, so the
list below is grouped into daily sets in priority order. None of this is required —
the sitemap alone will get everything crawled eventually. Manual requests buy days,
not outcomes.

## Day 3 — the cross-canonicalised guides (9 URLs)

**Submit these even though you do NOT want them indexed.** Each one now carries a
`rel=canonical` pointing at the matching guide on my-peptides.co.uk. Requesting
indexing triggers a recrawl, and a recrawl is exactly how Google discovers the new
canonical tag. The outcome you are looking for in Search Console is these URLs
moving to **"Alternate page with proper canonical tag"** — that status means the
canonical was accepted and the signal has consolidated onto the storefront.

Do not remove them from the sitemap until that status appears. Removing a URL slows
